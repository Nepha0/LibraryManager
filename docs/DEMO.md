# 课程演示版说明

## 演示目标

演示版用于确认 Qt、SQLite 和四个模块接口能够形成完整闭环。它不是最终成品，
后续仍需补充分类编辑、实体册管理、续借、预约、逾期处理和权限细分。

## 演示账号与数据

- 管理员：`admin` / `admin123`
- 读者编号：`R001`
- 首次运行自动生成两本虚构样书和四个可借实体册
- 本地数据库不进入 Git

## 建议演示顺序

1. 登录并展示工作台统计数据。
2. 在图书页面新增一本书，填写复本数并保存。
3. 在读者页面新增读者，或直接使用 `R001`。
4. 在借还页面选择 `R001` 和一本实体册借出。
5. 展示统计页面的借阅流水，然后返回并归还该书。
6. 再次刷新统计，说明实体册已经恢复可借。
7. 导出 CSV，说明后续可直接用于报告数据。

## 当前业务规则

- 借书与还书在同一数据库事务中更新借阅记录和实体册状态。
- 同一实体册只能存在一条未归还记录。
- 达到借阅上限或读者停用时拒绝借书。
- 管理员才能新增馆藏和读者；管理员与馆员可以办理借还。
- 密码在数据库中保存加盐 SHA-256 摘要，不保存明文。
- SQL 使用绑定参数，演示数据均为虚构内容。
