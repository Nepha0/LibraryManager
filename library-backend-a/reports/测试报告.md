## 三、缺陷记录与修复（开发过程中发现并已修复）

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | addBook 缺少 category_id 时未被必填校验拦截，直接触发数据库 NOT NULL 约束返回 DbError | validateFields 将分类纳入创建期必填校验，返回 MissingField"必填字段缺失：分类" |
| 2 | 检索服务 `Result r = queryBooks(..., &r.total)` 存在 C++17 拷贝消除下的写覆盖问题，total 恒为 0 | 改为独立局部变量接收 total 后再赋给 Result |
| 3 | 高级检索馆藏状态值非法时仍被计入有效条件，"条件全部非法"判断失效 | 仅在条件实际生效时递增 validConditions |
| 4 | queryBooks 分页查询未拼接排序子句，排序参数无效 | 修复 SQL 拼接，排序/分页全部生效 |
| 5 | fetchCopyRow 返回的 Result.data 为空，addCopy/updateCopy 无法返回副本详情 | 补充 data 填充 |

## 四、遗留说明（非缺陷）

1. roundtrip 用例重开内存库时会出现一条 `QSqlDatabasePrivate::removeDatabase: connection is still in use` 警告——源于服务对象持有旧连接拷贝，属测试写法提示，功能验证不受影响（相关用例全部通过）。业务代码中服务应随连接生命周期构建。
