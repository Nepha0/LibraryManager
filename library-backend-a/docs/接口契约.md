## 1. 统一返回结构

```cpp
struct Result {
    ErrorCode    code;      // 错误码（见 §2），前端按 code 分支处理
    QString      message;   // 具体原因，可直接透出给用户展示
    QVariantMap  data;      // 单条记录 / 统计数据（字段见各接口说明）
    QVariantList list;      // 记录列表（每项 QVariantMap，字段见各接口说明）
    int          total;     // 分页查询的总记录数
    bool ok() const;        // code == Success
};
```

前端处理约定：
- `ok()` 为 false → 展示 message（错误信息已按"透出给用户可读"撰写，无需前端自行拼文案）。
- 分页接口：`list` 为当前页数据，`total` 为总数；请求页超出范围时返回空 list 且 total 不变。
- 检索空条件：`ok()==true` 且 `total==0`（message 说明"条件为空"），不是错误。

## 2. 统一错误码

| code | 枚举 | 含义 |
|---|---|---|
| 0 | Success | 成功 |
| 1001 | NotAuthenticated | 未登录 / 会话失效 |
| 1002 | NoPermission | 无权限（读者越权、非管理员操作维修/报损副本等） |
| 1003 | MissingField | 必填字段缺失（message 注明字段名） |
| 1004 | ForeignKeyNotFound | 外键不存在（如分类不存在） |
| 1005 | IsbnDuplicate | ISBN 重复 |
| 1006 | BarcodeDuplicate | 副本条码重复 |
| 1007 | IllegalStatusTransition | 非法状态转换（message 含当前状态中文名） |
| 1008 | HasBorrowRecords | 存在借阅记录，拒绝物理删除（提示使用下架） |
| 1009 | CategoryInUse | 分类被图书引用，拒绝删除 |
| 1010 | BookNotFound | 图书不存在 |
| 1011 | CopyNotFound | 副本不存在 |
| 1012 | CategoryNotFound | 分类不存在 |
| 1013 | BookShelvedOff | 图书已下架（不可再借出/不可新增副本） |
| 1014 | EmptyCondition | 检索条件为空（返回空结果，非错误） |
| 1015 | InvalidCondition | 检索条件非法（message 含逐条原因） |
| 1016 | InvalidPage | 分页参数非法（page≥1，pageSize≥1） |
| 1017 | NameDuplicate | 名称重复（分类名等） |
| 1018 | FileError | 文件读写错误 |
| 1019 | FormatError | 文件格式错误（空文件/缺列/不支持的后缀） |
| 1999 | DbError | 数据库错误 |

## 3. 状态枚举（前端 Badge 文案与颜色对照）

### 图书状态
| 值 | 文案 | 建议色 |
|---|---|---|
| active | 正常 | 绿 |
| shelved_off | 已下架 | 灰 |

### 副本状态
| 值 | 文案 | 建议色 |
|---|---|---|
| available | 在馆可借 | 绿 |
| borrowed | 借出 | 蓝 |
| reserved | 预约保留待取 | 橙 |
| maintenance | 维修中 | 红 |
| lost | 遗失报损 | 红 |

### 副本状态机（唯一合法转换源：CopyService）

```
available   → borrowed（C:借阅）| reserved（C:预约触发）| maintenance | lost
borrowed    → available（C:归还）| reserved（C:归还且有预约）
reserved    → borrowed（C:预约者取书）| available（超时释放/取消）
maintenance → available（恢复）| lost（终结）    ← 仅管理员
lost        → available（恢复）                 ← 仅管理员
```

## 4. 操作者上下文

所有写操作与查询均需传入 `OperatorContext`（由 B 板块 AuthService 登录后生成）：

```cpp
struct OperatorContext {
    qint64 userId; QString userName;
    Role role;              // Admin / Librarian / Reader
    bool authenticated;
};
```

A 侧防御性规则：`authenticated=false` → 1001；Reader 调用管理操作 → 1002；维修/报损副本的恢复与终结仅 Admin → 1002。正式权限矩阵拦截在 B 板块。

## 9. AdvancedSearchService

| 方法 | 签名 | 说明 |
|---|---|---|
| advancedSearch | (op, conditions, sortBy, ascending, page, pageSize) → Result(list, total) | sortBy：title / publish_date / available；conditions 见下 |

conditions（QVariantMap，均可省略）：

| 键 | 类型 | 匹配方式 |
|---|---|---|
| titles | QStringList | 模糊，同类 OR |
| authors | QStringList | 模糊，同类 OR |
| isbn | QString | 精确 |
| categoryIds | QVariantList\<int\> | 精确，同类 OR |
| publishers | QStringList | 模糊，同类 OR |
| yearFrom / yearTo | int | 出版年区间（含边界） |
| copyStatus | QString | available（可借）/ UNavailable（不可借） |
| locations | QStringList | 模糊，同类 OR |

规则：类别间 AND；全部非法 → 1015；部分非法 → 忽略并经 message 提示；空条件 → 空结果。

注意：副本状态不参与导入/导出，导入副本一律置 available；CSV 为 UTF-8（带 BOM 兼容 Excel），日期格式 yyyy-MM-dd。

## 12. 与其他板块的对接点（给 B/C）

- **C 借阅流程**：borrow 时先 `getCopyByBarcode`（校验 available）→ 插借阅记录 → `changeCopyStatus(op, copyId, "borrowed")`；归还走 `changeCopyStatus` 至 available/reserved。
- **B 权限**：A 的 OperatorContext 由 B 的 login 会话生成；B 落地正式权限矩阵后可收敛 A 的防御校验。
- **B 参数**：A 不读取系统参数；书/副本表不含逾期费率相关字段（已按需求去除费用相关项）。
- **schema**：A 牵头 books/categories/book_copies；loans 的"单副本单有效借阅"唯一索引已建好（B/C 直接复用）。
