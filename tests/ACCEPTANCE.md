# 手工验收清单

完成后填写实际结果、测试人、日期及关联提交，不提前标记通过。

- [ ] 干净克隆后可以构建启动。
- [ ] 错误密码、停用账号不能登录；读者不能执行管理员操作。
- [ ] 图书、实体册、读者的新增与编辑能持久保存。
- [ ] 书名、作者、编号查询得到正确结果。
- [ ] 借书成功且记录和实体册状态一致；同册不能重复借出。
- [ ] 超出借阅额度、停用读者借书时被拒绝。
- [ ] 还书成功；同一借阅不能重复归还。
- [ ] 续借和预约遵守已确认的规则。
- [ ] 读者仅能查看自己的借阅；管理员能查看全部。
- [ ] 有未结借阅的实体册不能删除，相关读者不能直接注销。
- [ ] 统计与导出数据和实际借阅一致。
- [ ] 程序重启后数据仍然正确。
- [ ] 在另一台目标电脑上打包运行成功。
